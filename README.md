# Healthcare Operations & Clinical Outcomes Analytics Dashboard

## 📌 Project Overview
An end-to-end data analytics solution built using **MySQL Workbench** and **Power BI** to analyze **55,500+ patient records**. The project focuses on operational efficiency, billing revenue trends, length of stay (LOS), and clinical test outcomes.

---

## 🛠️ Tech Stack & Tools
- **Database:** MySQL Workbench (CTEs, Window Functions, Views)
- **Business Intelligence:** Power BI Desktop (DAX, Interactive Data Visualizations)
- **Data Pipeline:** Bulk Data Ingestion (`LOCAL INFILE`) & Analytical Modeling

---

## 📊 Key Highlights & Metrics
- **Total Patients Analyzed:** 55,500 (55.5K)
- **Total Billing Revenue:** ~$1.42 Billion
- **Average Length of Stay (LOS):** 15.51 Days
- **Abnormal Test Outcome Rate:** 33.56%
